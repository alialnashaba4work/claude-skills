# متجر جرار

موقع متجر جرار (زيت زيتون، زعتر، سماق، تتبيلات وهدايا) بالعربي والإنجليزي.

## التشغيل

الموقع ملفات ثابتة بدون أي بناء. افتح `index.html` من أي سيرفر بسيط، مثلاً:

```bash
cd jerar-store && python3 -m http.server 8000
```

وبعدها افتح http://localhost:8000

## الملفات

- `index.html` هيكل الصفحة
- `site.js` المنتجات والأسعار والنصوص والعرض (`OFFER`) والسلة
- `app.js` الصفحة الرئيسية وصفحات المنتجات والتنقل
- `search.js` البحث
- `cartbar.js` شريط السلة تحت الشاشة
- `receipt.js` السلة على شكل إيصال، كود الخصم وطرق الدفع
- `stockists.js` قسم «منتجاتنا متوفرة في»
- `journey.js` رحلة الزيتون (شجرة ← زيتونة ← تنكة ← قنينة)
- `pages.js` سياسة الخصوصية
- `extras.js` ميلان صورة المنتج وشريط التنقل في الجوال
- `style.css` التصميم
