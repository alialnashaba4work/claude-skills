# ديوان السيد محمد الماجد

لوحة لتصفّح قصائد خادم أهل البيت (ع) السيد محمد الماجد وإدارتها.

## الأقسام
أبيات مدح · أبيات رثاء · أبيات مناجاة · أخرى · مجالس كاملة

## التصنيفات
- **اللهجة:** فصيح / شعبي (دارج)
- **الشخصية:** الرسول (ص)، أمير المؤمنين (ع)، الزهراء (ع)، الحسين (ع)، العباس (ع)، زينب (ع)… (وتُضاف شخصيات جديدة من النموذج)
- **النوع:** عمودي / مجاريد / فايزي / حر / أخرى
- **روابط الإلقاء** إن وُجدت: يوتيوب يُعرض داخل الصفحة، وملفات mp3 تُشغَّل مباشرة.

## التشغيل
افتح `index.html` في المتصفح، أو انشر المجلد كما هو على GitHub Pages / Netlify. لا يحتاج إلى خادم.

## إضافة القصائد
1. من زر **«إضافة قصيدة»**. تُحفظ الإضافات في متصفحك.
2. لنشرها للجميع: **«تصدير البيانات»** ← ينزّل ملف `data.js` ← استبدل به الملف الموجود في المجلد.

أو عدّل `data.js` مباشرة (الشرح في أعلى الملف). كل بيت في سطر، وافصل بين الشطرين بالرمز `|`.

> القصائد الحالية في `data.js` نماذج توضيحية فقط، وليست من شعر السيد.

## الخط
خط **ثمانية Serif** (Thmanyah Serif Text / Display)، والملفات محفوظة في مجلد `fonts/`.
