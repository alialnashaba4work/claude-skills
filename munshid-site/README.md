# موقع المنشد

موقع عربي متوافق مع الجوال، بدون أي مكتبات أو خوادم خاصة. يكفي رفع المجلد على أي استضافة ثابتة (مثل GitHub Pages أو Netlify).

## الملفات
- `data.js`: كل محتوى الموقع (اسم المنشد، الأقسام، المواسم، المقاطع والنصوص).
- `audio/`: ملفات الصوت (`sample.mp3` ملف تجريبي فقط، احذفه بعد رفع الملفات الحقيقية).
- `img/`: صورة البنر والغلاف والأيقونات.
- `fonts/`: خط عبر (Abar Mid) بأوزانه الخمسة.

## إضافة مقطع
افتح `data.js` وأضف داخل `items` في القسم المطلوب:

```js
{ id: "r10", title: "اسم القصيدة", audio: "audio/اسم-الملف.mp3",
  text: "صدر البيت | عجز البيت\nصدر البيت | عجز البيت\n\nمقطع جديد..." }
```

- `id` لازم يكون بالإنجليزي وغير مكرر داخل نفس القائمة.
- كل سطر في النص بيت، والسطر الفارغ يبدأ مقطعاً جديداً، وعلامة `|` تفصل الصدر عن العجز.
- الأقسام الفرعية (مثل المواسم حسب السنة، أو الشهور داخل الموسم) توضع في `groups`، ويمكن تداخلها بأي عدد من المستويات.

## المزايا
- مشغل على شكل أسطوانة: تدور أثناء التشغيل وتنزل الإبرة عليها.
- الصوت يستمر عند قفل الجوال أو التنقل بين صفحات الموقع، مع أزرار التحكم في شاشة القفل.
- زر ملء الشاشة (على آيفون: "إضافة إلى الشاشة الرئيسية" من Safari يفتح الموقع بملء الشاشة).
- النص قابل للتحديد والنسخ، مع زر نسخ وزر تكبير وتصغير الخط.
- زر تحميل الصوت لكل مقطع.

## التجربة محلياً
```bash
cd munshid-site && python3 -m http.server 8000
```
ثم افتح `http://localhost:8000`.
