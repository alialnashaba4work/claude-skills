# Shelf store · متتبع منتجات شلف

متتبع إنتاج لفريق متجر شلف: كل المنتجات حسب الأولوية (A وB)، مع الحالة والمسؤول والمراجعة والثيم والخطوات.

## المحتوى

- `index.html`: صفحة المتتبع كاملة (التصميم والكود والخطوط والشعار داخل الملف).

## المميزات

- بطاقات وعرض قائمة، وبحث وفلاتر حسب الأولوية والشخص والثيم والحالة
- نافذة تعديل بشكل كوبون: الاسم والأيقونة والأولوية و«عاجل» والحالة والثيم والملاحظات والمسؤولين والخطوات
- إضافة أشخاص وثيمات جديدة من القوائم
- أرشيف للمنتجات المكتملة
- تنزيل Excel، وتقرير PDF بحجم A4 مع معاينة، وتقرير لكل شخص
- نسخة احتياطية واسترجاع

## التشغيل

الصفحة مبنية كـ Artifact على claude.ai، وتعتمد على خدماته:
- `db` لحفظ المنتجات ومشاركتها بين الفريق
- `user` لمعرفة صلاحية التعديل
- `downloads` لتنزيل Excel وPDF والنسخة الاحتياطية

لو فتحت `index.html` مباشرة من المتصفح، يطلع التصميم بس بدون بيانات.

## ملاحظة عن الخط

الخط العربي CoFo Sans Pro Arabic نسخة تجريبية (للتجربة فقط). لازم تشتري رخصته من arfonts.net قبل أي استخدام فعلي.
