# Shelf store · متتبع منتجات شلف

متتبع إنتاج لفريق متجر شلف: كل المنتجات حسب الأولوية (A وB)، مع الحالة والمسؤول والمراجعة والثيم والخطوات.
يشتغل من GitHub Pages كصفحة عادية، والبيانات مشتركة بين الفريق عن طريق قاعدة بيانات Supabase المجانية.

## الملفات

- `index.html`: صفحة المتتبع كاملة (التصميم والكود والخطوط والشعار داخل الملف).
- `config.js`: رابط قاعدة البيانات ومفتاحها.
- `setup.sql`: تجهيز قاعدة البيانات، ومعه المنتجات الحالية.

## التشغيل (مرة وحدة)

### 1. قاعدة البيانات (Supabase)
1. سو حساب مجاني في supabase.com، وبعدين **New project**.
2. افتح **SQL Editor**، والصق محتوى `setup.sql` كامل، واضغط **Run**.
3. من **Project Settings > API** انسخ:
   - **Project URL**
   - **anon public key**
4. حطهم في `config.js` بين علامات التنصيص، واحفظ الملف في المستودع.

### 2. الصفحة (GitHub Pages)
1. في المستودع على GitHub: **Settings > Pages**.
2. تحت **Build and deployment** اختر **Deploy from a branch**، والفرع اللي فيه المجلد، والمجلد `/ (root)`، واضغط **Save**.
3. بعد دقيقة أو دقيقتين، المتتبع يشتغل على:
   `https://alialnashaba4work.github.io/claude-skills/shelf-store/`

## المميزات

- بطاقات وعرض قائمة، وبحث وفلاتر حسب الأولوية والشخص والثيم والحالة
- نافذة تعديل بشكل كوبون، وإضافة أشخاص وثيمات جديدة
- أرشيف للمنتجات المكتملة
- تنزيل Excel، وتقرير PDF بحجم A4 مع معاينة، وتقرير لكل شخص
- نسخة احتياطية واسترجاع
- التعديلات تطلع عند الكل مباشرة
